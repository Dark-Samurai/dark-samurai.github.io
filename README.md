<details>
<summary><b>🔍 &nbsp;recon-suite</b> — detaylar için tıkla</summary>

<br/>

> Reconnaissance sürecini tek hatta toplayan modüler araç seti.

```bash
# Kurulum
git clone https://github.com/khontkar/recon-suite
cd recon-suite && ./install.sh

# Kullanım
./recon.sh <target-domain>

# Modüller
├── subdomain enum       (subfinder + amass)
├── port scan            (naabu + nmap)
├── http probe           (httpx + nuclei)
├── screenshot           (aquatone)
├── osint                (theHarvester + sherlock)
└── report               (markdown + json)
```

**Tech Stack:** `Python` · `Bash` · `Go` · `Docker`

</details>

<details>
<summary><b>🕵️ &nbsp;log-analyzer</b> — detaylar için tıkla</summary>

<br/>

> Büyük hacimli erişim loglarında gerçek zamanlı anomali tespiti.

```bash
./log-analyzer --input /var/log/auth.log \
               --rules  ./rules/ \
               --output alerts.json \
               --live
```

**Özellikler:**
- ✅ Real-time log streaming
- ✅ YAML tabanlı kural motoru
- ✅ MITRE ATT&CK eşleme
- ✅ Slack/Discord webhook bildirim
- ✅ Parquet + JSON export

**Tech Stack:** `Go` · `YAML` · `SQLite`

</details>
